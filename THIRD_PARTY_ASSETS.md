# Third-party art assets

Pixel Defense 3D can import the following coherent KayKit art set. The source
files are downloaded locally by `tools/assets/fetch_kaykit_cc0.sh`; they are
not committed to this repository.

| Pack | Author | License | Source |
| --- | --- | --- | --- |
| KayKit Medieval Hexagon Pack 1.0 | Kay Lousberg | CC0 1.0 Universal | https://github.com/KayKit-Game-Assets/KayKit-Medieval-Hexagon-Pack-1.0 |
| KayKit Character Pack: Adventurers 1.0 | Kay Lousberg | CC0 1.0 Universal | https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0 |
| KayKit Character Pack: Skeletons 1.0 | Kay Lousberg | CC0 1.0 Universal | https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0 |

The repositories each include their own `LICENSE.txt`. CC0 permits personal
and commercial use without attribution. Crediting Kay Lousberg/KayKit remains
appreciated.

Assets bought or claimed through Epic/Fab are not automatically copied into
this Git repository. Import them through Unreal's Fab window; keep their
original license and marketplace records.
