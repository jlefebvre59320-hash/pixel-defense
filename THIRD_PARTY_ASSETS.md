Source files are downloaded locally and are not committed to this repository.

The KayKit repositories each carry their own `LICENSE.txt`. CC0 permits
personal and commercial use without mandatory attribution. Crediting Kay
Lousberg/KayKit remains appreciated.

Poly Haven assets are downloaded through its public API at setup time. The API
integration identifies itself as PixelDefense3D and the project credits it as
**Powered by Poly Haven**, as requested by the API terms. Downloaded assets
themselves remain CC0.

Assets claimed through Epic/Fab are not automatically copied into Git. Import
them through Unreal's Fab window and retain their marketplace license records.
